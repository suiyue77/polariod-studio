测光不是让整张照片尽可能亮，而是帮助相机决定相纸应该接收多少光。对 Flip 来说，最有用的顺序是：**先选你想保留细节的主体，再观察它和背景的明暗差，最后决定是否补光、锁定曝光或调整 EV。**

本文的操作以 Polaroid Flip 为准；光学原理也适用于其他相机，但各机型的测光范围、补偿档位和闪光控制不能直接互换。

## 01 测光究竟在测什么

**反射式测光**从相机一侧观察物体反射回来的光。相机既受到照明强度影响，也受到物体本身明暗、反射率和取景范围内其他物体的影响。即使在同一束光下，白衣服与黑衣服反射的光也不同。

**入射式测光**在主体所在位置测量落到它身上的光。专业测光表的白色半球罩常用于这种测量；它不必先猜物体有多白或多黑。对于稳定光线下的静物和人像，这是理解照明的好方法。

一般反射式测光以中间调为基准；将单一白色物体测成中间调容易使它偏暗，将单一黑色物体测成中间调容易使它偏亮。这不是说 Flip 会精确地把每张照片变成 18% 灰。厂商没有公开足以复现其测光权重和全部自动曝光决策的资料。

*原创原理示意，不是 Flip 试拍，也不表示相机的实际测光分区。*

## 02 为什么有时候天空很好看，人脸却很黑

相纸能记录的明暗范围有限。逆光时，天空或窗口可能比阴影中的脸亮很多。若优先保留天空，脸可能变暗；若优先保留脸，天空可能失去细节。

比起先加曝光补偿，更值得尝试的是：

- 改变站位，让脸接收到更多环境光，或者寻找没有刺眼亮斑的背景。
- 在人物与相机的合适距离内用闪光灯补光，缩小人物和背景的光线差。
- 选择你真正想保留的细节。剪影也是合理的创作结果，不一定是废片。

更多场景：[人像用光：顺光、侧光和逆光](/learn/portrait-light/)。

## 03 Flip 的半按快门：锁定的不只是焦点

将主体放在取景器中心，半按快门。Flip 会锁定**对焦与曝光**，保持半按、轻微调整构图，再完全按下。

不要为了测一块较亮或较暗的区域，把相机先对准距离完全不同的背景，再转向人物；这样可能把对焦和闪光的距离依据一起改变。若主体位置、距离或光线发生变化，应松开并重新半按。

Flip 的声呐负责距离信息，自动选择适合的对焦区间；它不等于光度计，也不意味着对焦准确就会曝光准确。不要把半按锁定描述成独立的点测光模式。

## 04 学会看红灯，再决定拍不拍

半按快门时，根据取景器红灯与背部显示组合判断。曝光警告和正在设置 EV 补偿的图标是不同状态。

| 半按时的提示 | 含义与操作 |
| --- | --- |
| 红灯未亮 | 未提示这类异常；仍需检查光线和构图。 |
| 红灯常亮，EV 图标上方横线 | 预计偏亮，仍可拍。先检查强光、闪光和曝光补偿。 |
| 红灯常亮，EV 图标下方横线 | 预计偏暗，仍可拍。先找更多光或合适的补光。 |
| 红灯闪烁，显示 c | 主体太近（约 40 cm 以内），快门被阻止；后退并重新半按。 |

**没有红灯也不是成片保证。** 主体与背景的反差、相纸状态和显影条件仍会影响结果。

## 05 曝光补偿 EV：在自动曝光的基础上微调

机身长按 MODE 进入补偿设置，短按 MODE 切换三个档位，再长按确认退出；约 7 秒不操作也会退出并保存最后选择。拍下一种场景前记得核对设置。

| 档位 | 意图 |
| --- | --- |
| −0.5 EV（下方横线） | 希望相机减少曝光 |
| 0 EV（中间横线） | 以自动曝光判断作为起点 |
| +0.5 EV（上方横线） | 希望相机增加曝光 |

从曝光量的定义看，增加半档相当于理想目标量乘以约 1.41，减少半档约乘以 0.71；不是最终照片亮度直接乘以该系数。光圈、快门、闪光灯的实际控制边界和相纸响应都会影响结果。

0 EV 适合作为普通场景的基线。面对高反射的雪地、白墙或亮衣服，若主体被测得太暗，可尝试加半档；若阳光下画面已偏亮、重要高光丢失，则考虑减半档。面对深色主体或大片黑背景，若深色被抬得过亮，可尝试减半档。**不要机械使用“白加黑减”**：先判断主体照明、背景占比、闪光和预期效果。

## 06 闪光灯与外置测光表

Flip 的闪光灯会根据距离调整输出，标称最远约 4.5 米（f/8 条件）。这一规格不能理解成 4.5 米内的人脸与背景必然同样明亮。近处人物和远处墙面可能出现很大亮度差。

对于输出固定的近似点光源，忽略环境光和明显反射的理想场景，距离变成两倍，照度约变成四分之一，也就是少约两档。对真实闪光人像，这只是解释距离效应的近似模型，不是 Flip 的闪光输出公式。

普通手机测光 App 或手持环境光测光表可以帮助比较不同站位的相对光线；它们不必然和 Flip 自动曝光一致，也不能凭环境光读数预测内置闪光灯最终输出。想控制快门和光圈时，可以使用支持 Flip 的 Polaroid App 手动模式，先确认自己的 App 与固件版本。初学者无需为此购买测光表。

## 07 用三张相纸做一个小实验

这是 Studio 提议的练习方法，尚未在本站进行真实相纸对照试验，不是已验证的相机标定数据。

固定同一个人、背景、站位、相纸批次、光线和闪光设置，先在光线稳定的场景拍 0 EV，再分别试 −0.5 EV 和 +0.5 EV。每次重新半按，记录相机提示、距离、天气与显影温度。相纸按包装说明避光等待相同时间，再在同一光线下比较照片。若要扫描，也尽量使用相同设置。

不要一次改变闪光、距离、光线和 EV，否则很难知道哪项导致差异。每次拿起相机前先问：**我的主体是谁？哪个区域必须保留细节？我能不能先调整光线？**
