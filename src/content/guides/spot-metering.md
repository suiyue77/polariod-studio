用测光 App 不一定是为了让相机取代自动曝光。它最有用的价值，是在消耗相纸之前，帮你看见肉眼容易忽略的明暗差距。

**先测主体、背景和重要高光，再决定改变光线还是改变曝光。** 这篇文章把摄影者公开分享的经验与通用测光原理、Flip 的实际规格分开；示例读数是教学假设，不是 Studio 实拍数据。

## 01 场景反差与相纸宽容度不是一回事

当你分别测量人脸、背景和阴影时，保持相同的 ISO、测光方式和光线条件。使用一致的 EV 刻度，最大读数减去最小读数，就是所选区域间的亮度档数差。

| EV 差（档） | 两处亮度比 |
| --- | --- |
| 1 EV | 2:1 |
| 2 EV | 4:1 |
| 3 EV | 8:1 |
| 4 EV | 16:1 |
| 5 EV | 32:1 |

每增加一档，亮度比增加一倍。这是光学关系，不等于相纸能保留多少细节。相纸能记录的范围、在某个场景容许的曝光误差，以及摄影者能接受的高光和阴影效果，是三个不同概念。

不要把曝光补偿当作缩小反差的手段：只改变整体曝光时，人脸和背景原本的亮度比并不会改变。真正减少现场反差，需要改变照明、站位、背景或构图。

## 02 社区案例：先选要保留的区域

小红书作者泥人在一篇测光案例中，先对天空、建筑和前景等重要区域分别点测，再根据它们的差距选择曝光。作者个人希望重点区域的读数尽量控制在约 3–4 EV 内；其手动曝光实践还包括把亮部放到中间调之上，而不是直接将最亮区域当作中间灰。

这提供了一个值得复用的**拍前筛选方法**，但不是 Polaroid 发布的相纸动态范围，也不是任何相机都适用的参数公式。原笔记没有提供能够独立确定所有相纸批次宽容度的受控测量；本站不采用其设备购买建议、滤镜建议或固定补偿值作为通用要求。

实际使用中，先找你希望有纹理的亮部与暗部。太阳、灯泡、镜面高光等不一定需要保留细节，不必把它们机械地纳入每次测光。

## 03 Lightme：不用急着买专业测光表

Lightme 的开发者说明支持多组等效光圈与快门组合、可变测光区域的点测光、平均测光等功能。它可以帮助比较场景亮度；不同手机镜头、测光范围、校准状态以及低光条件都可能影响读数，并不能保证等同于专业 1° 点测光表。

以 Flip 和常规彩色 i-Type 为例：

1. 按相纸包装和官方规格设定感光度；当前常规彩色 i-Type 标称 ASA 640。不要把 ISO 640 当成所有即时相纸的统一感光度。
2. 使用同一手机镜头与测光方式，选择适合构图的预设。先不加个人经验补偿，避免将不同设置的读数混在一起。
3. 从相机预定拍摄位置观察场景。分别测人脸、想保留纹理的背景和主要高光。记下各区域的读数或同一参考曝光下的相对档数。
4. 若 App 显示多组光圈、快门组合，先选择相机真正支持的参数。测光 App 的推荐值不等于已经写入相机；自动模式仍由相机决定实际曝光。

小红书上一则 Flip 新手求助及其评论也反映了这个常见困惑：测光软件给出参数组以后，下一步还需要在相机支持的范围内选取参数。本文没有在真实手机上验证 Lightme 当前版本的具体按钮位置，以 App 内说明和实际界面为准。

## 04 教学例子：为什么不能只对背景测光

假设同一 ISO、同一测光刻度下，手机测得：

| 取样区域 | 假设读数 |
| --- | --- |
| 脸部 | EV 9.5 |
| 墙面 | EV 10.5 |
| 天空 | EV 12.5 |

从脸到天空相差 3 EV，亮度比为 8:1。如果把天空作为曝光参考，脸部会比天空暗三档；如果让脸更亮，天空可能过亮。实际照片上的色调仍取决于曝光放置、相纸和显影条件。

此时可以优先让人物转向开阔天空、换到更均匀的光线、调整取景范围；如果相机距离和环境允许，再考虑闪光补光。不要为了把脸提亮而盲目增加整体 EV。

另一位使用 I-2 的摄影者分享了先比较背景与脸部测光结果、再决定是否补光的思路。可以借鉴这个判断顺序，但不直接采用其人脸 EV、滤镜补偿、闪光距离等经验数值作为 Flip 的标定值。

## 05 把测光读数转成 Flip 真正能拍的设置

Flip 官方说明书列出的普通快门范围为 1/200–1 秒，App 模式为 1/200–30 秒及 B 门；可用光圈依对焦区间而定。机身自动曝光补偿为 −0.5、0、+0.5 EV。

| 你在使用的模式 | 如何利用外部测光 |
| --- | --- |
| Flip 机身自动 | 把手机当作场景检查工具；调整光线和构图，再对实际主体半按，检查警告、距离和 EV。 |
| Flip 通过 Polaroid App 手动 | 选择当前相机、对焦区间和 App 允许的快门与光圈；在稳定环境光下进行对照。 |
| I-2 或其他可手动相机 | 按该机型的实际参数范围设定，不直接套用到 Flip。 |

例如，一组假设的环境光读数是 f/8.5、1/400 秒。Flip 无法按这个快门拍摄；在相同感光度下，约 f/12、1/200 秒是近似等效曝光组合。实际只能选当前模式支持的档位；若不存在合适组合，应改变光线或接受不同曝光，而不是假称已实现等效设置。

这一换算只适用于相同环境光下的近似曝光量。手机环境光测量不能直接预测 Flip 瞬时闪光、自动输出、相纸色调响应或实际成片亮度。

## 06 同一个场景、同一自动模式，为什么有的照片过曝？

一则公开 Flip 求助描述了在同一场景使用自动模式和闪光灯，有些人物过亮，有些正常。它说明这个问题确实值得研究，但没有足够的受控数据证明声呐、背景、闪光或相纸是唯一原因。

建议按以下顺序排查：

- 核对实际人物距离和半按时相机瞄准的位置，不要先对远处背景锁定曝光和焦点再转向近处人脸。
- 保持人物和相机距离，检查闪光是否开启、是否就绪，避免同时改变多个条件。
- 比较人脸和背景的环境光读数；看是否需要换站位，或在条件允许时关闭闪光进行对照。
- 记录当前补偿、相纸批次、温度和显影避光情况，不能仅凭一张照片确定相机故障。

参见[废片诊断](/learn/photo-diagnosis/)及[测光基础](/learn/metering/)。

## 07 不花相纸也可以先做一次测光练习

先用同一手机选好感光度，分别测三个场景：均匀窗光、窗前逆光、室内深色背景。每个场景只记主体、背景和重要亮部的读数，比较最大与最小值。

然后选择一个反差较明显的场景，改变人物朝向或站位，重复测量。优先比较现场亮度差是否真的减少，再决定拍摄。若之后使用真实相纸测试，保持同批相纸、显影条件和单一改变变量，并记录闪光及相机设置。本站目前没有完成这组真实相纸对照，不将练习方案描述为实测结果。
