# Wish interpretation

首页引导 Learn、Creators、Gallery；教程可独立阅读，创作者只有 approved=true 才公开，图库以明确许可的作品替换样例；无真实内容时如实显示状态。

- `/` → editorial entry; `/learn/` → guides; `/creators/` → approved creators; `/gallery/` → approved photos or explicitly labelled samples.
- [Content schema](../../src/content.config.ts) and the existing PhotoSwipe viewer own those rules.

Visual rules and their executable owner are in [Design](../design/README.md); implementation and release rules are in [Dev](../dev/README.md).
